# План: поиск работы и подготовка откликов

Цель: один Telegram-бот для удалённых вакансий и фриланс-заказов из RU и зарубежных источников. Поиск работает без профиля. Профиль нужен только для текста отклика и заполнения формы. Любую отправку пользователь проверяет и подтверждает отдельно.

## Реализовано

1. **Несколько источников.** Общий интерфейс поиска; HeadHunter, Remotive, We Work Remotely, Freelancer.com и Freelancehunt. Для вакансий дополнительно подключены открытые API Remote OK и Jobicy, их можно включить в боте. SuperJob доступен при наличии ключа, FL.ru RSS — если лента открывается из сети пользователя. Ошибка одного источника не отменяет результаты остальных.
2. **Два раздела поиска.** В главном меню отдельно открываются вакансии и заказы; у каждого свой запуск, фильтры и история. Вакансии отбираются по роли, названию и стеку. Заказы по умолчанию ищутся на Freelancer.com и Freelancehunt среди проектов по разработке ПО: страна заказчика не фильтруется, техническая тема ищется в названии или описании, а теги навыков учитываются при явном запросе на реализацию в названии. Дизайн, маркетинг, мобильные и чужие технические роли исключены по умолчанию. Для заказов отдельно настраиваются источники, темы, стоп-слова, свежесть и лимит. Результат отклика открывается отдельной кнопкой. Бюджет проекта показывается, но пока не служит фильтром.
3. **Профиль и шаблоны.** В главном меню бота есть отдельный раздел «👤 Профиль»: основное, навыки и опыт, ссылки и резюме, условия работы и дополнительные факты. Локальный профиль можно также создать командой `job-search profile --init`. Данные кандидата и дополнительные факты хранятся в локальном файле; сообщения для их редактирования проходят через Telegram. Есть отдельные шаблоны для RU/международной работы и фриланса. Для поля анкеты приоритет: значение в шаблоне → стандартное поле профиля → дополнительный факт с точным названием. Бот не придумывает недостающие сведения.
4. **Анкеты.** Поиск явной ссылки на форму, предварительная проверка Tilda и простых HTML-форм, заполнение известных полей, прикрепление файла резюме через обычный input или Uploadcare на Tilda. Неизвестные поля и согласия остаются для ручной проверки. Перед отправкой сохраняются снимок и отчёт; отправка требует подтверждения конкретной подготовленной анкеты. Неясный результат блокирует повторную отправку.
5. **Автозапуск.** Ежедневный поиск по времени и часовому поясу; настройки доступны в Telegram и сохраняются между перезапусками. Для компьютера, который выключается, подготовлен пример службы Linux VPS. Служба у пользователя ещё не развёрнута. При работе без экрана бот присылает снимок подготовленной формы перед предложением отправить её.

## Следующие интеграции и условия

- **Больше RU-заказов:** Freelancehunt API подключён. FL.ru RSS 28.09.2026 один раз ответил HTTP 200, но повторные запросы получили HTTP 403, поэтому источник не включён в раздел заказов. Kwork и Freelance.ru показывают публичные проекты, но официального API/RSS для их автоматического поиска пока не подтвердили. Habr Freelance отвечал HTTP 410. Публичную HTML-страницу не считаем автоматически устойчивым API.
- **Upwork:** в официальном GraphQL API есть поиск проектов, но нужен API-ключ и разрешение `Read public marketplace Job Postings`. В текущем окружении ключ не настроен, поэтому источник не включён и живой поиск не проверен.
- **Качество фриланс-поиска:** первичная живая проверка 28.09.2026 получила 99 проектов; после ужесточения технического фильтра прошло около двух десятков. Это не ручная оценка точности: проверить каждую карточку, затем добавить фильтры бюджета и условий отклика без некорректного сравнения разных валют. Сейчас API отдаёт ограниченную страницу свежих проектов, поэтому полнота поиска не доказана. Ежедневное расписание пока запускает только вакансии.
- **Точнее подбирать зарубежные предложения:** отдельно учитывать право на работу, страны найма, язык, валюту и минимальный бюджет. Пока бот показывает заявленные ограничения, но не делает вывод, что «remote» доступно из любой страны. Для персональной фильтрации нужны реальные сведения пользователя.
- **Больше анкет:** добавлять адаптеры под конкретные ATS и типы форм после проверки реальных страниц. Вход в аккаунт, OTP, CAPTCHA и неизвестные виджеты остаются ручными. Универсального безопасного автозаполнения всех сайтов не обещаем.
- **Эксплуатация:** развернуть службу на выбранном сервере, проверить работу расписания и Telegram на реальном аккаунте. Нужны токен бота, разрешённый Telegram ID, выбранные поисковые фразы и при желании профиль; эти данные не входят в Git.

## Как проверить сейчас

1. `job-search doctor` — конфигурация и браузер.
2. `job-search scan` — разовый поиск; проверить число новых результатов и ошибки источников.
3. `job-search bot` — кнопки поиска, истории, источников, профиля и шаблонов в личном чате.
4. На тестовой публичной форме проверить подготовку и снимок. Отправлять настоящую заявку только после сверки всех полей и подтверждения в боте.
5. `python -m pytest -q`, `python -m ruff check .`, `python scripts/privacy_scan.py .` — локальные проверки перед публикацией кода.
